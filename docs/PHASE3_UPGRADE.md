# الترقية الاحترافية — PHASE 3 (لوحة الأداء)

لوحة أداء (Dashboard) كصفحة HTML مستقلة تُولَّد تلقائيًا من حساب التداول الورقي +
سجل الصفقات، تعرض الحالة والأرقام بلمحة. تُحدَّث كل ساعة مع دورة البوت الورقي.

## الملفات المُضافة

| الملف | الدور |
|---|---|
| `deals_bot/performance.py` | حساب المقاييس: العائد، نسبة النجاح، عامل الربح، التوقّع، **أقصى تراجع** (من منحنى رأس المال)، السلاسل |
| `dashboard.py` | يقرأ الحساب + السجل، يحسب الأداء، ويولّد `dashboard.html` (مستقل، متجاوب، يدعم الوضعين الفاتح/الداكن) |
| `tests/test_performance.py` | اختبارات التراجع الأقصى، منحنى رأس المال، المقاييس |

## ما تعرضه اللوحة

- **الحالة:** يعمل (تداول ورقي) + شارة «التداول الحقيقي: مُعطَّل».
- **KPIs:** رأس المال، العائد٪، التوقّع/صفقة، نسبة النجاح، عامل الربح، أقصى تراجع،
  الصفقات المفتوحة، صافي الربح/الخسارة.
- **منحنى رأس المال** المُحقَّق (SVG).
- **الأفضلية المُثبتة:** داخل العيّنة +0.38R، خارج العيّنة (Walk-Forward) +0.19R.
- **محرّك المخاطر:** 0.5%/صفقة، 1.5% يومي، 3 خسائر، RR 1:2.
- **جداول:** الصفقات المفتوحة + آخر الإشارات المسجّلة.

## التشغيل

```bash
python dashboard.py          # يولّد dashboard.html من أحدث بيانات
python -m pytest -q          # الاختبارات
```

يُعاد توليد اللوحة وحفظها في المستودع تلقائيًا مع كل دورة `paper-bot.yml`.

## الأمان
اللوحة للقراءة فقط؛ لا تنفّذ تداولًا. كل الأرقام من التنفيذ الورقي والباك-تِست.
