# الترقية الاحترافية — PHASE 2 (الحلقة الحيّة الورقية + Walk-Forward)

تربط خط القرار + محرّك المخاطر + التنفيذ الورقي في **حلقة بوت حيّة** تفتح وتراقب
وتقفل صفقات ورقية تلقائيًا، وتضيف **اختبار المشي الأمامي** لإثبات صمود الأفضلية
خارج العيّنة. لا أموال حقيقية — Paper فقط.

## الملفات المُضافة

| الملف | الدور |
|---|---|
| `deals_bot/bot_loop.py` | دورة الحلقة: مراقبة المفتوحة → أمان يومي → فتح المعتمد عبر `pipeline.evaluate` |
| `deals_bot/walkforward.py` | Walk-Forward: تدريب العتبة داخل العيّنة واختبارها خارجها عبر عدة طيّات |
| `paper_bot.py` | نقطة تشغيل الحلقة الورقية + إشعارات تيليجرام + حفظ الحساب |
| `.github/workflows/paper-bot.yml` | تشغيل الحلقة كل ساعة وحفظ الحساب/السجل في المستودع |
| `tests/test_phase2.py` | اختبارات Walk-Forward + الحلقة (إغلاق عند الهدف، إيقاف بعد 3 خسائر) |

كما أُضيف في `backtester.py` حدّا `entry_min_ts` / `entry_max_ts` لتقييد نافذة الدخول
(أساس الـ Walk-Forward، بلا look-ahead)، وفي `paper_trading.py` تتبّع اليوم
(`roll_day`) لإعادة ضبط حدّ الخسارة اليومية.

## حلقة البوت (دورة واحدة)

```
roll_day (إعادة ضبط أساس اليوم)
   ↓
مراقبة كل صفقة مفتوحة → check_exit (وقف/هدف) → close_position + إشعار
   ↓
بناء حالة اليوم من الحساب (خسارة يومية + خسائر متتالية)
   ↓
بوّابة الأمان اليومية (توقف لو تجاوز 1.5% أو 3 خسائر)
   ↓
لكل مرشّح: pipeline.evaluate → APPROVED؟ → open_position (Paper) + إشعار
   ↓
حفظ الحساب + السجل
```

## Walk-Forward (لماذا؟)

الباك-تِست العادي قد «يطابق» فترة واحدة. المشي الأمامي يقسّم التاريخ إلى طيّات:
في كل طيّة **يدرّب** العتبة على نافذة، ثم **يختبرها على النافذة التالية غير المرئية**.
التوقّع الموجب خارج العيّنة = تعميم حقيقي، لا مبالغة في المطابقة.

```bash
python backtest.py --market crypto --timeframe 1h --strategy walkforward
```

## أوامر التشغيل

```bash
python -m pytest -q                 # كل الاختبارات (offline)
python paper_bot.py                 # دورة تداول ورقي واحدة (Paper فقط)
python backtest.py -m crypto -t 1h --strategy walkforward   # اختبار خارج العيّنة
```

## الأمان

- `LIVE_TRADING_ENABLED=False` — `paper_bot.py` يرفض العمل لو فُعِّل التداول الحقيقي.
- محرّك المخاطر يوقف الحلقة تلقائيًا عند حدّ الخسارة اليومية أو 3 خسائر متتالية.
